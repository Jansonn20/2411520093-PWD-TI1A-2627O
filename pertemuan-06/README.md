# Pertemuan P6

Pada pertemuan 6 proyek web dari pertemuan sebelumnya dikembangkan dengan menggunakan PHP untuk membuat halaman profil menjadi dinamis.

## 2. Fitur dan Pengembangan
- Mengubah `index.html` menjadi `index.php`.
- Mempelajari variabel, konstanta, dan tipe data PHP.
- Menerapkan operator, percabangan, dan perulangan.
- Menampilkan informasi profil menggunakan PHP.
- Menggunakan fungsi PHP untuk menampilkan IPK dan tahun secara dinamis.

## 3. Pengujian
Pengujian dilakukan melalui localhost menggunakan Laragon untuk memastikan halaman dapat dijalankan dan kode PHP menghasilkan keluaran sesuai dengan yang diharapkan.

## 4. Riwayat Pengembangan
- Menyiapkan proyek dari pertemuan sebelumnya.
- Menambahkan kode PHP pada halaman profil.
- Menerapkan percabangan dan perulangan.
- Melakukan pengujian dan memperbaiki kesalahan jika ditemukan.

Tidak ditemukan adanya galat ataupun error selama pengujian
