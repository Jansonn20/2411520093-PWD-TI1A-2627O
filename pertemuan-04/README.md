# Pertemuan 4 - CSS3 Layout dan Responsive Web Design
## Pengembangan
- Perubahan yang dilakukan: Memisahkan style dari index.html ke style.css dan membuat we menjadi responsif
- Commit dan push GitHub: 
1. Memisahkan CSS dari index.html ke dalam style.css.
2. Menerapkan CSS Box Model pada elemen halaman.
3. Menerapkan Flexbox untuk penataan navigasi.
4. Menerapkan Desain Responsif
5. Update Perkembangan di Readme.md
## Pengujian
- Perangkat bergerak: 
Untuk ukuran kurang dari 768px
HASIL: 
-navigasi Beranda, Tentang, dan Kontak tersusun secara vertikal
-bagian Home, Tentang Saya, dan Contact tersusun dalam satu kolom
-seluruh konten tetap dapat ditampilkan dan digunakan dengan baik

- Desktop: 
Untuk ukuran lebi dari 768px

-navigasi Beranda, Tentang, dan Kontak tersusun secara horisontal
